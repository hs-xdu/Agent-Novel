# 拾光 · 小说写作助手

一个在本地运行的 AI 小说写作工作台，基于 Python 3.12、PySide6 和 Pydantic。当前处于 MVP 阶段，推荐使用原生桌面版，保留 NiceGUI 网页兼容入口。

## 已实现

- 多小说项目管理，基础设定、全书大纲、分卷大纲与章节规划。
- 一页式章节创作：确认大纲、生成正文、人工审阅、选段改写和定稿。
- 从定稿正文提取摘要、人物状态、时间线和伏笔；失败可重试，冲突需人工审阅。
- 软件内配置模型 API、密钥、超时及独立的正文 / 记忆整理思考强度。
- 本地 Markdown / JSON 修订快照、编辑缓存、未完成正文候选及 Markdown 导出。
- 中文错误指引、可复制的失败详情与错误编号。

## 快速开始（Windows）

安装 Python 3.12+ 和 uv，在项目目录执行：

```powershell
uv sync --locked
uv run python -m app.desktop
```

安装依赖后，也可双击根目录的 `启动拾光.cmd`。

首次打开，点击右上角 **大模型 API 设置**，填写服务商对应的接口协议、基础地址、模型名称及 API 密钥，测试连接后保存。桌面版支持 Responses 和 OpenAI 兼容 Chat Completions，具体能力取决于服务商与模型。没有密钥时可选择 `demo` 体验固定示例流程。

## 基本流程

新建小说 → 完善项目信息 → 确认基础设定 → 确认全书及分卷大纲 → 开始章节 → 审阅并确认本章大纲 → 生成并编辑正文 → 确认定稿 → 同步记忆 → 继续下一章。

AI 结果先作为候选或草稿，审阅确认后才成为正式内容。若记忆整理失败，已定稿正文保留；按中文提示修正设置或处理冲突后重试，无需重写正文。记忆同步前暂停后续章节的 AI 生成。

“记忆整理思考强度”默认关闭，“正文思考强度”默认低。输出 token 上限与等待超时不同；思考可能占用输出预算，增加超时不能解决输出预算耗尽。模型不支持指定思考档位时可选择服务商默认。

## 数据与验证

小说保存在本地 `projects/`，API 密钥通过系统凭据库保存。`.env`、小说数据、桌面设置、日志及打包产物不上传仓库。桌面保存设置后以桌面配置为准；请勿在多个实例中同时写入同一小说目录。备份时关闭应用并复制完整数据目录。

```powershell
$env:QT_QPA_PLATFORM='offscreen'
uv run pytest -q
Get-ChildItem tests/Verify-*.ps1 | ForEach-Object { & $_.FullName }
```

自动化测试主要验证流程、存储与错误恢复，不代表真实模型的长篇创作质量。真实 API 的兼容性、额度与内容质量仍需实际验收，项目还在持续调试。
